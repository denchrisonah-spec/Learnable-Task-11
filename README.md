# Airport Career Portal

A streamlined, highly optimized React web application for exploring open aviation careers across Nigerian airports. Built with Vite, React 19, and TypeScript.

## 🚀 Features

*   **Job Listings & Details**: Browse open airport roles with full descriptions, salary estimates, and custom tags.
*   **Department Filters**: Filter jobs dynamically by departments (Security, Ground Services, Operations, etc.).
*   **Interactive Search**: Live search roles instantly by job title, company, or location.
*   **Sleek & Clean Styling**: Premium user interface with CSS transitions, zero external styling libraries, and zero inline hover listener overhead.

## 📦 Tech Stack

*   **Core**: React 19, TypeScript, HTML5
*   **Styling**: Vanilla CSS (modularized utility classes)
*   **Bundler/Server**: Vite 8

## 🛠️ Getting Started

### 1. Install Dependencies
Install only the absolute necessary packages for building and running:
```bash
npm install
```

### 2. Start Development Server
Launch the local dev server:
```bash
npm run dev
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

### 3. Production Build
Compile and bundle the production assets:
```bash
npm run build
```
The optimized bundle will be generated under the `dist/` directory.
